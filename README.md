# ROS2_LT — 라인트레이서 제어 프로젝트

서울과학기술대학교 CORE 연합동아리 라인트레이서 대회를 위한 Arduino UNO 기반 제어 코드입니다.
적외선 센서 2개로 라인을 따라가고, 초음파·조도센서로 가림판과 천장 가림막을 감지해 정지한 뒤 제거되면 재출발하는 것을 목표로 합니다.

> **개발 중:** 센서 개별 테스트와 배선 점검 단계입니다. 통합 주행과 대회 완주는 아직 검증하지 않았습니다. 저장소 이름은 ROS2_LT이지만 현재 구현은 Arduino 스케치이며 ROS 2 노드는 포함하지 않습니다.

## 개발 환경

- Arduino UNO / Arduino IDE / PlatformIO 
- Arduino C++ / 외부 라이브러리 불필요
- 시리얼 모니터: **115200 baud**
- VS Code + PlatformIO 환경과 Arduino IDE 환경 둘 다 사용합니다.

## 구성 파일

| 파일 | 용도 |
|---|---|
| [통합 제어 코드](firmware/line_tracer/line_tracer.ino) | 라인 추종, 장애물 정지·재출발, 보정 및 출발 명령 |
| [왼쪽 적외선 단독 테스트](tests/ir_left_a2/ir_left_a2.ino) | 왼쪽 센서 AO를 UNO A2에서 읽는 최신 진단 코드 |

각 스케치는 독립 프로그램입니다. 하나를 업로드하면 UNO에서 실행되는 이전 프로그램은 교체됩니다. 세 파일을 같은 스케치에 합치지 않습니다.

## 하드웨어

| 부품 | 구성 |
|---|---|
| 제어보드 | Arduino UNO |
| 모터드라이버 | L298N 2채널 모듈 |
| 구동부 | 지급 DC 기어드모터 2개 |
| 라인 센서 | TCRT5000 적외선 모듈 2개, AO·DO·GND·VCC |
| 거리 센서 | HC-SR04 초음파센서 1개 |
| 조도 센서 | CdS GL5528 1개, 10kΩ 분압 저항 사용 예정 |
| 배터리 | 7.4V / 2200mAh |
| 회로 구성 | 빵판에서 개별 검증 후 만능기판으로 이관 예정 |

최근 테스트에서는 조도센서가 연결되지 않았습니다. 조도센서가 없는 상태에서 통합 제어를 실행하거나 밝기 보정을 하지 않습니다. 연결하지 않은 아날로그 핀에서 나오는 값은 실제 센서 측정값이 아닙니다.

## 전원 연결

배터리의 +와 -를 각각 분기해 두 보드에 공급합니다.

| 대상 | 연결 |
|---|---|
| UNO | DC 전원잭, 중앙 + / 바깥 - |
| L298N | 배터리 + → 모터전원 `12V/VS`, 배터리 - → `GND` |
| 센서 | UNO `5V`와 `GND`에서 분배 |

- `12V`는 L298N 모듈의 모터전원 단자 표시입니다. 입력한 7.4V 배터리 전압이 자동으로 12V가 되는 것은 아닙니다.
- 센서나 UNO 5V 핀에 배터리 원전압을 직접 연결하지 않습니다.
- L298N의 5V 단자는 전원 점퍼 설정에 따라 입력/출력 역할이 달라집니다. UNO 5V와 임의로 연결하지 않습니다. 실제 모듈의 논리전원 설정을 확인해야 합니다.
- 배터리 -가 UNO 전원잭과 L298N GND에 연결되면 공통 접지가 형성됩니다. 모터 전원 귀환선은 배터리 분기점으로 직접 연결합니다.
- 모터 정격, 모터 전류에 맞는 전선과 드라이버 발열을 확인합니다. 배터리 방전 또는 모터 기동 시 전압 강하로 UNO가 재부팅되는지도 시험합니다.
- 배선 변경은 USB와 배터리를 모두 분리한 상태에서 진행하고, 노출된 접합부는 각각 절연합니다.

## 통합 코드 핀맵

최근 변경한 좌우 모터 매핑을 반영했습니다. **왼쪽 모터는 OUT3·OUT4, 오른쪽 모터는 OUT1·OUT2** 기준입니다.

| UNO | 연결 대상 |
|---|---|
| D5 | L298N ENA — 오른쪽 속도 |
| D7 / D8 | L298N IN1 / IN2 — 오른쪽 방향 |
| D6 | L298N ENB — 왼쪽 속도 |
| D9 / D10 | L298N IN3 / IN4 — 왼쪽 방향 |
| A0 | 왼쪽 적외선 AO |
| A1 | 오른쪽 적외선 AO |
| A2 | CdS 분압 중간점 |
| D4 | HC-SR04 TRIG |
| D2 | HC-SR04 ECHO |
| D12 ↔ GND | 선택 사항: 시작/정지 버튼 |

PWM 속도 제어에는 ENA·ENB 점퍼캡을 제거하고 신호 핀에 연결합니다. 전원용 5V-EN 점퍼와 구분해야 합니다. 전진 방향이 반대인 바퀴는 `REVERSE_L` 또는 `REVERSE_R` 설정을 변경합니다.

### 최신 단독 테스트와 통합 배선의 차이

**`ir_left_a2` 테스트에서는 왼쪽 센서 AO → UNO A2입니다.** 오른쪽과 조도센서는 사용하지 않습니다.

통합 코드로 돌아갈 때는 왼쪽 센서를 **A0로 되돌리고**, 오른쪽은 A1, 조도는 A2에 연결합니다. A2를 두 센서 출력에 동시에 연결하지 않습니다.

센서 `AO`는 아날로그 출력, `DO`는 디지털 출력입니다. UNO의 핀 이름 A0/D0와 같은 의미가 아닙니다.

- AO 사용: `DIGITAL_IR=false`, 0~1023 범위로 읽습니다. 검은색에서 반드시 1023이 되는 것은 아닙니다.
- DO 사용: 센서 신호선을 DO로 변경하고 `DIGITAL_IR=true`로 설정합니다. 내부 판정은 0/1이며, 검은 선에서의 실제 출력을 확인해 `DIGITAL_LINE_LEVEL`을 맞춥니다.
- 통합 코드의 진단 로그 L/R는 DO 모드에서도 `analogRead`로 출력됩니다. 디지털 모드 여부를 그 로그 숫자만으로 판단하지 않습니다.

## 센서 단독 테스트

1. 모터 배터리를 분리하고 노트북 USB로 UNO에 전원을 줍니다.
2. 왼쪽 센서 VCC → 5V, GND → GND, AO → A2로 직접 연결합니다. DO는 비웁니다.
3. `tests/ir_left_a2/ir_left_a2.ino`를 업로드합니다.
4. 시리얼 모니터를 115200 baud로 열고 `Left(A2)=...`를 확인합니다.
5. 감지면 높이를 일정하게 유지한 채 흰 바닥과 검은 선의 측정값을 기록합니다.

센서 LED 변화는 모듈의 판정 변화일 수 있지만 AO/DO 신호가 UNO까지 전달되는지까지 보증하지는 않습니다. 문제가 있으면 같은 전선·같은 입력 핀에 다른 센서를 연결하여 비교합니다.

## 모터 단독 테스트

`tests/motor_test/motor_test.ino`를 업로드합니다. 바퀴를 띄우고 시험합니다.

전원 투입/리셋 → 3초 대기 → 왼쪽 5초 → 정지 2초 → 오른쪽 5초 → 정지 2초 → 양쪽 5초 → 정지.

`setup()`에서 한 번만 실행하며 자동 반복하지 않습니다. 실제 전진 방향과 좌우 매핑은 바퀴를 띄워 확인합니다.

## 통합 제어 실행

모든 센서가 정상 연결되고 개별 검증된 뒤 실행합니다.

1. `firmware/line_tracer/line_tracer.ino`를 Arduino IDE에서 엽니다.
2. 보드 Arduino UNO와 연결 포트를 선택하여 업로드합니다.
3. 시리얼 모니터를 115200 baud로 열고, 정지 상태에서 아래 보정을 수행합니다.

| 명령 | 동작 / 준비 상태 |
|---|---|
| `w` | 좌우 센서 모두 바닥색을 보는 상태에서 보정 |
| `b` | 좌우 센서 모두 라인색을 보는 상태에서 보정 |
| `c` | 실제 조명에서 천장 가림막 없이 밝기 보정 |
| `g` | 준비 조건이 만족되면 1.5초 대기 후 출발 |
| `x` | 정지 |

센서 2개를 한꺼번에 같은 색에 올릴 수 있도록 넓은 보정면을 사용합니다. 기본 아날로그 모드에서는 각 센서의 선/바닥 차이가 100 이상이어야 보정 준비 조건을 통과합니다. 이 수치는 코드의 초기 기준이며 센서 상태를 검증하면서 조정해야 합니다.

**보정값은 RAM에만 저장됩니다.** 전원이 끊기거나 리셋되면 보정값과 출발 상태가 초기화됩니다. 업로드한 프로그램 자체는 남습니다. 따라서 현재 통합 코드는 배터리만 꽂으면 자동 주행하는 완성 버전이 아닙니다. 독립 주행용 보정값 저장/시작 절차는 추가 개발 항목입니다.

## 제어 방식

- **라인 추종:** 좌우 아날로그 신호를 보정한 후 차이를 오차로 사용하여 PD 제어합니다.
- **센서 배치:** 중앙 정렬 시 적어도 한 센서가 선을 보는 배치가 필요합니다. 둘 다 바닥색이면 라인 유실로 판단합니다.
- **초음파:** 18cm 이하에서 정지, 24cm 이상 3회 측정 시 해제합니다. 무응답 5회에도 해제하므로 장애물 제거와 센서 단선은 구별하지 못합니다.
- **조도:** 밝기 기준의 65% 미만이 80ms 지속되면 정지, 80% 초과가 250ms 지속되면 해제합니다. 필터 지연이 추가됩니다.
- **동시 감지:** 초음파와 조도 중 하나라도 정지 조건이면 정지를 유지합니다.
- **라인 유실:** 마지막 감지 방향으로 짧게 복구를 시도하고 450ms 안에 찾지 못하면 정지 상태를 유지합니다. 재정렬 후 `x`, `g` 순으로 재시작합니다.
- **정지 방식:** L298N EN=LOW로 구동을 해제하는 자유 정지이므로 관성 이동을 고려해 정지거리를 시험합니다.

기본 속도 PWM=105, 최대 PWM=165, Kp=65, Kd=0.30입니다. 모두 초기값이며 실제 모터·노면에 맞춘 튜닝이 필요합니다. DO 방식은 신호가 불연속이므로 Kd=0부터 시험할 수 있습니다. 결승선 자동 인식은 포함하지 않습니다.

## 현재 진행 상태

| 항목 | 상태 |
|---|---|
| 전원 분기 | UNO·L298N 전원 LED 점등 확인 |
| 모터 테스트 | 단독 구동 코드 작성 및 테스트 진행, 최종 결과 기록 필요 |
| 초음파 | 배선 수정 후 거리값 수신 확인, 반복 정지 시험 필요 |
| 적외선 | LED 반응 확인, AO 신호와 배선·입력 핀 진단 진행 중 |
| 조도 | 최근 테스트 시 미연결 |
| 통합 코드 빌드 | 대화에서 공유된 Arduino IDE 화면에 컴파일 성공 확인 |
| 실차 통합 주행 | 미검증 |
| 제작 | 센서 정상 확인 후 만능기판 납땜·차체 최종 배치 예정 |

이 묶음은 대화에서 작성한 코드를 정리한 버전입니다. 사용자 PC에서 별도로 수정한 모든 내용과 동기화된 것은 아닙니다. 통합 코드에는 최근 변경한 좌우 모터 핀 배치를 반영했으며, 이번 묶음 자체의 AVR 재빌드는 수행하지 않았습니다.
